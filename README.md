## 📌 About the Project

Dhiman's Kebab & Pizza Cafe Website is a web development project created to provide a digital presence for a restaurant. It uses frontend web technologies to build the website's interface.

The project demonstrates practical web development skills, including website structure, styling, interactivity, and the integration of different web technologies.

- 🍕 Restaurant website with food and cafe branding

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Git installed on your computer
- Visual Studio Code or another code editor
- A web browser

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/AmitojSingh121/DhimansKebabPizzaCafeWebsite.git
```

**2. Navigate to the project folder**

```bash
cd DhimansKebabPizzaCafeWebsite
```

**3. Open the project**

Open the folder in Visual Studio Code.

**4. Run the website**

If the project contains a standalone HTML entry point, open it using a browser or the VS Code Live Server extension.

If the website requires PHP, run it through PHP's built-in development server from the project directory:

```bash
php -S localhost:8000
```

Then open:

```text
http://localhost:8000
```

Make sure you use the correct entry file and any required configuration for the project.
